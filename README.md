# Newton's Laws: predict, commit, watch
Run: `npm install`, then `npm run dev` (play), `npm test` (physics), `npm run build` (static `dist/`).
Keys: Space/Enter = GO or continue · R = retry · 1–4 = jump to level · N = next level.

Levels: 1 Inertia (stop a puck) · 2 F = ma (land crates) · 3 Push back (throw to move) · 4 Finale (throw to go, throw to stop).

60-second demo (each step: ask the room "where does it end up?", tap their guess, GO):
1. (0–15 s) Level 1, press GO as-is. F = 0 N but v stays 3.00 m/s; it never stops.
2. (15–30 s) Press 2. Crate 1 lands. Crate 2 is 4 kg, same 20 N: stops at 5 m.
3. (30–45 s) Press 3, GO as-is: throw wrench at airlock, drift backward. Retry: drag aim away, pick Tank, win.
4. (45–60 s) Press 4, GO as-is: crash at 0.85 m/s. Read the card: "Nothing slows you down."
Finale solution: Kit ← at 0 m, Toolbox → at ~8.5 m (lighter you, same throw, bigger change).
