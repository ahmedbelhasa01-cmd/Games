# Newton's Laws — predict, commit, watch, learn
Run: `npm install` → `npm run dev` (play) · `npm test` (physics) · `npm run build` (static `dist/`).
Keys: Space/Enter = GO or continue · R = retry · N = next level.

Levels: 1 Inertia (built) · 2 F = ma cargo · 3 Throw to move · 4 Finale (all three) — in progress.

60-second demo (Level 1):
1. "Puck on frictionless ice. One push queued. Goal: stop it in the dock." (5 s)
2. Ask the room: "Where does it stop?" Hit GO, tap the dock as the guess. (10 s)
3. Point at F = 0 N while v stays 3.00 m/s. It sails past the guess, off screen. (15 s)
4. Read the card: "Force was zero, so speed stayed 3.00 m/s." (5 s)
5. Try again: tap track at ~12.5 m, tap again to flip it ←. GO. (10 s)
6. Orange F points back, v shrinks to 0, docked. Read the law line. (15 s)
